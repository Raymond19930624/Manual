手機配對與藍牙連線步驟

首次配對 (Pairing)
龍頭推入 + 長按右下按鈕 B
1. 打開手機「CITIZEN Bluetooth Watch」App。
2. 手錶龍頭保持推入（第 0 段），按住右下角 按鈕 B 2~3 秒。
3. 二手會指向「ACT」並移動至「CONNECT」，手機 App 點選確認配對。
手動連線 (Reconnect)
按住按鈕 B 2 秒
日常手動同步時間時，短按或長按按鈕 B 2 秒，秒針旋轉至 CONNECT 成功同步後自動歸位。
通知指針位置解讀
CALL / INFO / LL / ACT
• CALL：電話來電 ｜ • INFO：簡訊或 LINE 訊息 ｜ • LL：藍牙連線中斷提示 ｜ • ACT：正在搜尋通訊中。
Zero Position Calibration

指針基準位置校正（指針偏差修復）

🎯 指針位置對不準時的校準步驟：
1. 將龍頭向外拉出 兩段 (第 2 段)。
2. 同時長按右上角按鈕 A 與右下角按鈕 B 約 3 秒以上，指針微動發出嗶聲進入基準校準模式。
3. 按按鈕 A 切換要校正的指針（時針/分針/功能盤/小指針），旋轉龍頭調整指針精確對齊正 12 點鐘或正中央。
4. 全數對齊後，將龍頭推回第 0 段，完成校準。

GAME’NIR ProX-Legend7Ds 電玩手把使用指南

全方位跨平台無線遊戲手把。具備 Switch 遠端主機喚醒、Amiibo 感應、自訂雙背鍵巨集記憶、三段 TURBO 自動連發與 5 階震動調整。

24~30h 超長續航時間
950mAh 大容量電芯
20 Steps 背鍵巨集步數
5 段 馬達震動強弱
Pairing Methods

跨平台配對連線方式速查

Switch 主機
首次配對 & 遠端喚醒
• 首次連線：進入 Switch「控制器」➔「更改拿法/順序」，按住手把頂部配對鍵 3~5 秒至指示燈快閃。
• 後續喚醒：主機附近短按 HOME 鍵，即可連線並直接開機喚醒 Switch。
長按 B + HOME (2~3s)
PC / 手機：XBOX 模式（推薦）
長按 2~3 秒啟動配對，電腦或手機搜尋藍牙裝置「Xbox Wireless Controller」點選連線。相容 Steam、Windows 與大部分手遊。
長按 Y + HOME (2~3s)
PC / 手機：Switch Pro 模式
長按 2~3 秒啟動配對，藍牙搜尋「Pro Controller」，適用於 PC Steam 啟用陀螺儀體感映射。
PC 有線直插 / R3 特殊模式
USB 有線連接
隨插即用，預設偵測為 XBOX 模式；若 PC 有線要強制以 NS 模式連線，請按住 R3（右蘑菇頭下壓）再插上 USB 線。
Rapid Fire Feature

TURBO 連發功能設定

T 鍵 + 單擊動作鍵
長按連發 (Manual Turbo)
按住該動作鍵時持續連點，放開即停止。支援按鍵：A / B / X / Y / L / R / ZL / ZR。
T 鍵 + 雙擊動作鍵
全自動連發 (Auto Turbo)
完全放開手把也會自動持續連打！再次單按該動作鍵可「暫停/繼續」自動連打。
T + "+" / T + "-"
三段頻率調節
按 T 鍵搭配加號或減號切換頻率：5 次 / 12 次 / 20 次 每秒。
長按 T 鍵 5 秒
一鍵清除所有連發
立即重設並關閉當前所有按鍵的連發設定。
Macro & Button Memory

背面自訂鍵 (XL / XR) 巨集記憶錄製

單鍵對應 (Copy)
把單一按鈕複製到背面
1. 長按 ML 或 MR 鍵 3 秒（手把震動）。
2. 按下想複製的目標鍵（如 A 鍵）。
3. 再按一次 ML/MR 鍵結束（手把震動），XL/XR 即可作為該按鍵。
多鍵組合 (Macro 連招)
錄製組合技 (最多 20 步)
1. 長按 ML 或 MR 鍵 3 秒（手把震動）。
2. 依序輸入連招步驟（支援方向鍵、雙搖桿、動作鍵，可帶按壓間隔）。
3. 再按一次 ML/MR 儲存，按 XL/XR 即可一鍵施放連招！
清除巨集記憶
清空 XL / XR 背鍵
直接長按 ML 或 MR 鍵 3 秒，不按任何鍵直接放開，即可清除該背鍵功能。
長按 "-" + R/L 5秒
背鍵防誤觸鎖定
同時長按「減號鍵」與「R 鍵」或「L 鍵」5 秒（手把震動），可全面鎖定/解鎖背部巨集鍵，避免激戰誤觸。
Vibration & LEDs

馬達震動與指示燈含義

項目 操作方式 / 燈號狀態 說明
增強震動 按住背部右側震動鍵 震動力度 5 檔循環：100% ➔ 75% ➔ 50% ➔ 25% ➔ 0% (關閉)
減弱震動 按住背部左側震動鍵 逐步降低馬達回饋力度
Xbox 模式 (Xinput) 指示燈 LED 1 & LED 4 常亮 PC / 手機標準連線狀態
Switch 模式 (Dinput) 指示燈 LED 2 & LED 3 常亮 Switch 主機連線狀態
低電量警示 指示燈 緩慢閃爍 電量不足，請及時充電以防進入強制休眠保護
充電狀態 充電中：呼吸閃爍 ｜ 充飽電：常亮不滅 建議使用 5V 1A~2A 充電器，充飽約 2~5 小時
⚠️ 低電量保護提醒：手把若完全耗盡電量可能會觸發強制休眠保護。若手把長久未玩，再次使用前請先充飽電約 1 小時再行開機。

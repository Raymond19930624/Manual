Installation Notice

重要：4 顆背部運輸螺栓拆卸守則

🚨 極度重要安全警告：
新機背面原廠安裝了 4 顆運輸保護螺栓，用於在搬運過程中固定懸掛滾筒：
• 首次通電使用前，必須使用扳手將背部 4 顆螺栓全部卸下，並用隨附塑膠孔蓋封閉螺栓孔。
• 若未拆除螺栓就啟動脫水，高速運轉時會產生劇烈跳動、移位、發出巨響撞擊聲並嚴重損壞避震結構與內部滾筒。
Detergent Dispenser

洗滌劑分配盒 3 分槽投放指南

主洗槽 (標記 II)
主要洗滌劑投放格
放入日常洗衣粉、洗衣精或濃縮洗滌劑。若使用滾筒專用低泡洗衣精，能防止泡沫過多溢出。
柔順劑槽 (梅花圖標 ✿)
衣物柔軟精投放格
只能倒入液體柔軟精，液面絕對不可超過「MAX」最大刻度線，否則會在注水初期提早虹吸流失。
預洗槽 (標記 I)
預洗程序洗滌劑格
僅在選擇「預洗」功能（針對重度泥沙髒污衣物）時才需添加，一般日常標準洗衣請保持空置。

Error Code Matrix

原廠完整 E 系列故障代碼排除表

報警代碼故障名稱可能原因自查排除與解決方法
E01 / E10進水超時報警水龍頭未開、水壓不足、進水閥過濾網被水垢堵塞。打開水龍頭、檢查水壓、旋開進水管清理濾網雜質。
E02 / E12排水逾時受阻排水管被壓扁、排水管掛起高度過高、排污閥堵塞。理順排水管、清理右下角排污過濾器硬幣毛屑。
E03 / E20脫水不平衡報警洗滌物過少 (如單件毛毯) 捲成一團導致重心偏斜。暫停開門，抖散均勻分佈衣物，或增加一件毛巾配重重新脫水。
E04筒內溢水異常進水閥損壞無法關閉、水位感應器管路漏氣。立即拔掉電源插頭，關閉進水水龍頭，撥打報修。
U4 / dOOR機門未關閉鎖緊衣物夾在門框膠條處、門鎖未推緊扣入鎖孔。檢查門邊無衣物卡住，用力將機門推緊，聽到喀噠聲後按啟動。
